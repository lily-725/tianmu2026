# 展览左侧导航对齐地图侧栏计划

## Summary

- 目标：保持展览模块左侧侧边导航栏现有内容不变，仅将桌面端左栏的宽度、纵向布局节奏、激活态呈现方式，调整为与地图模块左侧导航栏同一套框架。
- 参考对象：`src/modules/map/components/Timeline.tsx` 中地图页左侧导航。
- 实施范围：展览模块桌面端左侧固定侧栏；移动端抽屉导航暂不调整。

## Current State Analysis

### 1. 展览模块左侧栏现状

- 入口位于 `src/components/Layout.tsx`。
- 桌面端左栏使用 `nav.exhibition-sidebar hidden md:flex w-56 sticky top-[78px] h-[calc(100vh-78px)] ...`。
- 左栏内部当前由三段组成：
  - 顶部 `exhibition-sidebar-card`，承载 “Exhibition Context / 天穆六百年 / Current Layer / 返回链接”。
  - 中部 `exhibition-sidebar-nav`，承载 “关于天穆 / 展览前言 / 漫步展厅 / 浏览展陈” 导航项。
  - 底部 `exhibition-sidebar-footer`，承载版权文案。
- 配套样式位于 `src/index.css`：
  - `.exhibition-sidebar-card`
  - `.exhibition-sidebar`
  - `.exhibition-sidebar-nav__link`
  - `.exhibition-sidebar-nav__label`
  - `.exhibition-sidebar-nav__indicator`
  - `.exhibition-sidebar-footer`

### 2. 地图模块左侧栏现状

- 入口位于 `src/modules/map/components/Timeline.tsx`。
- 外层结构为固定宽度 `w-56` 的纵向 `nav`，内部同样分为三段：
  - 中央主导航区：`flex-1 flex flex-col justify-center gap-8 w-full py-4 min-h-0`
  - 底部图例区：`mt-auto`
  - 激活态采用左侧竖条指示器 `absolute left-0 w-1.5 h-10`
- 该组件的布局特征是：
  - 容器较“平”，没有额外大卡片包裹主信息。
  - 主导航区垂直居中，项目间距统一。
  - 左缘激活态更直接，整体重心集中在导航列表本身。

### 3. 差异结论

- 宽度：两边目前都为 `w-56`，但展览左栏视觉上更“宽”，原因主要来自内部卡片、较大的内边距、底部独立 footer 区块和链接的横向留白。
- 布局：展览左栏当前是“顶部信息卡 + 中部导航 + 底部页脚”的展陈式布局；地图左栏更接近“纵向导航骨架”。
- 激活态：展览与地图都使用左侧指示条，但展览导航项缺少地图左栏的纵向节奏、透明度层级与集中对齐方式。

## Proposed Changes

### 1. 调整 `src/components/Layout.tsx`

- 保留左栏中所有现有文案、链接、顺序与返回逻辑，不改 `navItems` 与 `getExhibitionContext()` 的业务内容。
- 重组桌面端左栏 DOM，使其更贴近地图 `Timeline` 的三段式骨架：
  - 外层仍保留 `nav.exhibition-sidebar hidden md:flex w-56 sticky top-[78px] h-[calc(100vh-78px)] shrink-0`。
  - 将顶部信息区由“强调卡片”弱化为与地图左栏同节奏的顶部说明块，继续承载品牌、当前层级、返回链接。
  - 中部导航区继续使用现有 4 个链接，但改为更接近地图左栏的垂直居中列表结构。
  - 底部版权区收敛为地图左栏底部图例区那种贴边、整栏宽度的收口方式。
- 只处理桌面端 `md` 以上左栏，不改移动端 `md:hidden` 的 `exhibition-mobile-context` 与 `exhibition-mobile-panel` 结构。

### 2. 调整 `src/index.css`

- 以现有 `.exhibition-module-theme` 下的展览侧栏样式为主，收敛到地图左栏的布局节奏：
  - `.exhibition-sidebar`
    - 对齐地图左栏的整体 framing：更明确的纵向骨架、统一的左右 padding、顶部/底部区块分隔。
  - `.exhibition-sidebar-card`
    - 去掉“独立悬浮卡片”的强卡片感，避免让左栏视觉宽度显得大于地图左栏。
    - 保留内容，但使其表现为导航体系的一部分，而非单独视觉主角。
  - `.exhibition-sidebar-nav__link`
    - 对齐地图左栏条目的最小高度、左右内边距、纵向节奏与 hover/active 状态。
    - 让激活项的左侧指示条位置和尺寸更接近地图左栏。
  - `.exhibition-sidebar-nav__label`
    - 调整字号、字距与层级，使其更接近地图左栏的紧凑感。
  - `.exhibition-sidebar-footer`
    - 改为与地图底部图例区相同的“整栏底部收口”方式，弱化单独卡片/漂浮感。
- 保留展览模块自己的配色变量 `brand-*`，不直接替换为地图模块的 `archive-*` 视觉主题，避免把展览整体风格错误切换成地图主题。

### 3. 不计划改动的文件

- `src/modules/map/components/Timeline.tsx`
  - 仅作为参考，不直接修改。
- `src/modules/map/index.css`
  - 仅作为参考，不直接修改。
- 展览页内容页如 `src/pages/Exhibitions.tsx`、`src/pages/ExhibitionDetail.tsx`
  - 本次不改页面正文内容与主体栏宽度。

## Assumptions & Decisions

- 假设 1：用户所说“左侧侧边导航栏”指的是展览模块桌面端固定左栏，而不是移动端抽屉。
- 假设 2：用户希望“依照地图界面的左侧导航栏”主要指布局骨架与宽度节奏对齐，而不是把展览侧栏完整改造成地图配色与内容结构。
- 决策 1：左栏保留现有内容信息块，但弱化其独立卡片感，让其并入地图式纵向导航骨架。
- 决策 2：使用 `src/index.css` 中已有的展览模块样式选择器完成对齐，避免新增无必要的全局样式体系。
- 决策 3：不调整移动端导航，除非后续明确要求“桌面端与移动端一并统一”。

## Verification Steps

- 视觉核对
  - 打开展览模块任一页面，确认桌面端左栏宽度与地图页左栏一致，侧栏不再因卡片/留白显得更宽。
  - 确认左栏仍包含原有品牌信息、当前层级说明、返回链接、4 个导航入口和版权信息，内容无删改。
  - 确认导航区在纵向上更接近地图左栏：条目居中、节奏一致、激活态左侧指示条位置稳定。
- 交互核对
  - 切换 `/about`、`/foreword`、`/hall`、`/collection` 以及 `hall` 详情页，确认高亮逻辑与返回链接逻辑保持正确。
- 响应式核对
  - 缩小到移动端宽度，确认现有 `exhibition-mobile-context` 和 `exhibition-mobile-panel` 仍按当前逻辑工作，没有被桌面改动误伤。
- 质量核对
  - 实施后检查 `src/components/Layout.tsx` 与 `src/index.css` 的诊断信息，确保未引入新的语法或样式错误。
