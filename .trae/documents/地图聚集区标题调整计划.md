# 地图聚集区标题调整计划

## Summary

- 目标：将地图模块中明清、民国两个时期的单一“天穆老村”聚集区，拆分为用户提供的 4 个聚集区多边形，并把点击后的标题改为：
  - `穆家庄（穆庄子）`
  - `天齐庙`
  - `穆家庄（穆庄子） 民国`
  - `天齐庙`
- 保持点击呈现内容不变：沿用当前对应时期 `天穆老村` 的 `description` 与 `images`，不改详情内容结构、不改点击交互逻辑。
- 用户给出的 GeoJSON 坐标为 `[lng, lat]`，项目中的 `residentialAreas.points` 使用 `[lat, lng]`，实现时需要逐点转换。

## Current State Analysis

- `src/modules/map/data.ts`
  - `p1` 和 `p2` 的 `residentialAreas` 目前各只有 1 个区域，名称均为 `天穆老村`。
  - 点击详情所需的标题、描述、图片都直接来自每个区域对象：
    - `name` 决定标题
    - `description` 决定正文
    - `images` 决定图集
- `src/modules/map/components/MapDisplay.tsx`
  - 区域点击时调用 `onFeatureSelect({ title: area.name, images: area.images, description: area.description })`，说明只改 `area.name` 即可改标题，不会影响现有详情内容。
  - `cottagePositions` 通过区域 `id` 匹配老村装饰性房屋图标位置；如果仅替换 `data.ts` 中的区域 id 而不更新这里，明清/民国阶段的小房子图标会消失。
- `src/modules/map/types.ts`
  - `ResidentialArea` 结构已满足本次改动，不需要新增字段。

## Proposed Changes

### 1. 更新 `src/modules/map/data.ts`

- 将 `p1.residentialAreas` 从 1 个区域拆成 2 个区域：
  - `area-mujiazhuang-p1`
    - `name`: `穆家庄（穆庄子）`
    - `description`: 复用当前 `p1` 的 `天穆老村` 描述
    - `images`: 复用当前 `p1` 的 `天穆老村` 图片
    - `points`: 使用用户提供的“穆家庄（穆庄子）” GeoJSON，按 `[lng, lat] -> [lat, lng]` 转换
  - `area-tianqimiao-p1`
    - `name`: `天齐庙`
    - `description`: 同样复用当前 `p1` 的 `天穆老村` 描述
    - `images`: 同样复用当前 `p1` 的 `天穆老村` 图片
    - `points`: 使用用户提供的“天齐庙” GeoJSON，按 `[lng, lat] -> [lat, lng]` 转换

- 将 `p2.residentialAreas` 从 1 个区域拆成 2 个区域：
  - `area-mujiazhuang-p2`
    - `name`: `穆家庄（穆庄子） 民国`
    - `description`: 复用当前 `p2` 的 `天穆老村` 描述
    - `images`: 复用当前 `p2` 的 `天穆老村` 图片
    - `points`: 使用用户提供的“穆家庄（穆庄子） 民国” GeoJSON，按 `[lng, lat] -> [lat, lng]` 转换
  - `area-tianqimiao-p2`
    - `name`: `天齐庙`
    - `description`: 同样复用当前 `p2` 的 `天穆老村` 描述
    - `images`: 同样复用当前 `p2` 的 `天穆老村` 图片
    - `points`: 使用用户提供的“天齐庙” GeoJSON，按 `[lng, lat] -> [lat, lng]` 转换

- 不改 `p3`、`p4` 的聚集区数据。

### 2. 更新 `src/modules/map/components/MapDisplay.tsx`

- 在 `cottagePositions` 中补充 4 个新区域 id 的装饰房屋位置：
  - `area-mujiazhuang-p1`
  - `area-tianqimiao-p1`
  - `area-mujiazhuang-p2`
  - `area-tianqimiao-p2`
- 房屋点位按新多边形的包围范围手动放置在各自区域内部，保持明清/民国阶段点击区域之外的视觉氛围基本不变。
- 不修改区域点击逻辑本身，因为现有逻辑已经满足“标题变、点击内容不变”的要求。

## Assumptions & Decisions

- 决策：同一时期内拆出的两个聚集区共享当前该时期原有的详情正文和图片；这符合“点击呈现的东西不变，标题变一下”的要求。
- 决策：GeoJSON 只用于替换聚集区面，不影响道路、河流、点位、时间轴或右侧详情组件。
- 决策：使用新的区域 id，而不是沿用原 `area-core-p1` / `area-core-p2`，以便数据语义清晰、后续维护方便。
- 假设：用户希望明清和民国两个时期各拆成两个可点击面，而不是仅在现有单面基础上改名。
- 假设：`穆家庄（穆庄子）` 与 `天齐庙` 在同一时期内点击后展示相同内容是可接受的，因为用户明确要求“点击呈现的东西不变”。
