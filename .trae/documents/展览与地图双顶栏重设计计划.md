# 展览与地图双顶栏重设计计划

## Summary

- 目标：消除 `展览页面` 与 `地图页面` 当前的双顶部导航问题，重新整理导航层级，让页面只保留一套明确的顶部导航，同时保持全站风格统一、无重叠、无错乱、可正常跳转。
- 已确认的设计决策：
  - 首页继续使用站点总品牌名 `天穆地方史`。
  - 展览页顶部品牌名改为 `天穆六百年`。
  - 地图页顶部品牌名改为 `地图里的天穆村`。
  - 展览页原先顶部层级导航职责改由左侧栏承接，并以“返回上一级”为主。
- 约束：不改动现有业务路由结构，不破坏首页、展览、地图原有内容功能与跳转链路。

## Current State Analysis

### 1. 当前双顶栏的实际来源

- `src/components/SiteTopNav.tsx`
  - 现在作为全站统一顶部导航，负责 `首页 / 展览 / 地图` 一级跳转。
  - 顶部品牌标题目前固定写死为 `天穆地方史`，所有模块共用。
- `src/components/Layout.tsx`
  - 展览模块除了 `SiteTopNav` 之外，还有一层展览内部移动端顶部条：
    - 标题：`天穆六百年`
    - 按钮：`打开展览目录`
  - 桌面端左侧栏顶部也有一套展览标题区：
    - `Exhibition Index`
    - `天穆六百年`
  - 主内容顶部还存在一条 breadcrumb 条，承担 `首页 / hall / collection / about...` 的层级导航。
- `src/modules/map/components/Header.tsx`
  - 地图模块除了 `SiteTopNav` 之外，还有一个完整头部：
    - `Cartographic Chronicle`
    - `地图里的天穆村`
    - `Digital Evolution Archive • 当前时期`
    - `ACTIVE PERIOD`
  - 因为 `Header` 内又嵌入了 `SiteTopNav`，视觉上形成两层头部。

### 2. 导航职责现状

- `SiteTopNav` 当前同时承担：
  - 顶部品牌展示
  - 全站一级导航
  - 移动端站点菜单
- `Layout.tsx` 当前同时承担：
  - 展览侧栏目录
  - 展览移动端目录菜单
  - breadcrumb 层级导航
- 结果：
  - 展览页顶部信息过多，站点级导航、展览标题、breadcrumb 竞争同一层级。
  - 地图页顶部出现“站点导航 + 模块标题头”双层堆叠。

### 3. 现有路由与层级关系

- 由 `src/App.tsx` 可确认：
  - 首页：`/`
  - 地图：`/map`
  - 展览入口：`/exhibition`
  - 展览子页：`/about`、`/foreword`、`/hall`、`/hall/:exId`、`/hall/:exId/:unitId`、`/collection`、`/collection/:id`、`/team`
- 由 `src/components/Layout.tsx` 可确认，展览页天然存在明确的“上一级关系”：
  - `/hall/:exId/:unitId` -> `/hall/:exId`
  - `/hall/:exId` -> `/hall`
  - `/collection/:id` -> `/collection`
  - 其他展览一级页面 -> `/exhibition`
- 这使得“返回上一级”可以基于当前路径规则推导，无需新增用户输入。

### 4. 样式现状

- `src/index.css`
  - 已存在 `.site-top-nav` 及三套模块主题：
    - `.home-module-theme`
    - `.exhibition-module-theme`
    - `.map-module-theme`
  - 现有样式里把顶栏表现定义得较完整，但没有支持“不同页面品牌文案不同”的逻辑。
  - 地图模块移动端还有依赖 `header` 选择器的规则，会影响 `Header.tsx` 改造方式。

## Assumptions & Decisions

- 保留 `SiteTopNav` 作为唯一的站点级顶部导航组件，不再让展览和地图各自再出现第二套顶部品牌栏。
- `SiteTopNav` 品牌标题改为按页面变体切换：
  - `home` -> `天穆地方史`
  - `exhibition` -> `天穆六百年`
  - `map` -> `地图里的天穆村`
- 展览页的 breadcrumb 不再停留在主内容顶部横条位置，而改造成侧边栏中的“返回上一级”入口。
- 展览侧边栏仍保留内部目录能力，但其首屏区域优先展示上下级返回动作，而不是重复展示一层顶部导航语义。
- 地图页保留 `Header.tsx` 中的模块信息区，但移除其与顶部导航重复的标题承担方式，改成“模块说明区”，避免形成第二导航条。
- 首页不需要本次大改，只需确保统一顶栏逻辑支持首页品牌文案不变。

## Proposed Changes

### 1. 让统一顶栏支持页面级品牌文案

- 文件：`src/components/SiteTopNav.tsx`
- 做什么：
  - 为 `SiteTopNav` 增加按 `variant` 切换品牌标题与副标题的能力。
  - 保留一级导航 `首页 / 展览 / 地图` 与当前路由高亮逻辑。
- 为什么：
  - 当前顶部标题固定为 `天穆地方史`，无法满足“展览页改为天穆六百年、地图页改为地图里的天穆村”的要求。
- 怎么做：
  - 新增品牌配置映射，如 `brandByVariant`。
  - 将 `site-top-nav__brand-title` 与 `site-top-nav__brand-subtitle` 从硬编码改为按 `variant` 读取。
  - 保持首页 variant 不变，确保首页仍显示 `天穆地方史`。

### 2. 精简展览顶部，只保留一套站点级导航

- 文件：`src/components/Layout.tsx`
- 做什么：
  - 保留顶部的 `SiteTopNav` 作为唯一顶部导航。
  - 去掉展览主内容区顶部的 breadcrumb 横条。
  - 重新整理侧边栏与移动端目录，让它承接“返回上一级”。
- 为什么：
  - 目前展览页冲突主要来自：
    - 顶部 `SiteTopNav`
    - 展览移动端顶部条
    - 主内容顶部 breadcrumb
  - 其中 breadcrumb 与顶部导航功能重叠最明显，应移出顶部区域。
- 怎么做：
  - 将 breadcrumb 数据保留，但不再作为横向顶部条渲染。
  - 新增一个从当前路径推导“上一级页面”的函数，优先覆盖：
    - 单元详情 -> 专题详情
    - 专题详情 -> 展厅列表
    - 藏品详情 -> 浏览展陈
    - 展览一级页 -> 展览首页
  - 在桌面侧栏顶部加入一个显著的“返回上一级”动作区。
  - 在移动端目录抽屉顶部同样加入“返回上一级”入口，取代原先顶部层级导航的职责。

### 3. 重新定义展览侧栏的信息层级

- 文件：`src/components/Layout.tsx`
- 做什么：
  - 保留现有内部目录项：
    - `关于天穆`
    - `展览前言`
    - `漫步展厅`
    - `浏览展陈`
  - 但侧栏上半区改成：
    - 当前模块标题 `天穆六百年`
    - 当前所在页面或当前层级提示
    - `返回上一级`
- 为什么：
  - 用户明确要求把原有“首页/漫步展厅式”的导航功能移到侧边栏，并可以变为返回上一级。
- 怎么做：
  - 桌面端：在左侧栏 शीर्ष部加入 contextual action 区。
  - 移动端：保留目录弹层，但最上方先呈现“返回上一级”。
  - 目录项继续负责横向跳转，返回动作负责层级回退，两者职责清晰分离。

### 4. 去掉地图页的双头部感，保留一个顶部导航 + 一个说明区

- 文件：`src/modules/map/components/Header.tsx`
- 做什么：
  - 保留 `SiteTopNav`，并将其作为地图页唯一顶部导航。
  - 将 `Header` 中现有的模块标题区改为紧贴导航下方的说明区，而不是第二层导航条。
- 为什么：
  - 当前地图页视觉上的“双顶栏”来自：
    - 顶部 `SiteTopNav`
    - 下方另一个完整的模块头
  - 需要削弱第二层的“导航感”，保留“内容说明感”。
- 怎么做：
  - 在 `SiteTopNav` 的 map 变体中直接显示品牌标题 `地图里的天穆村`。
  - `Header.tsx` 下方信息区保留：
    - 当前时期说明
    - `ACTIVE PERIOD`
    - 模块副标题
  - 去掉或弱化重复的主标题文字层级，避免再次出现一套与顶栏同权重的标题。

### 5. 调整地图页头部布局节奏，避免重叠与压缩

- 文件：`src/modules/map/components/Header.tsx`
- 文件：`src/modules/map/App.tsx`
- 做什么：
  - 根据 `Header` 变薄后的结构调整高度与内边距，确保地图主体区域不被压缩得太多。
- 为什么：
  - 地图页是 `h-screen` 的三栏布局，顶部结构变化后容易出现内容高度错位。
- 怎么做：
  - 保持 `Header` 总体高度更紧凑。
  - 如有必要，仅微调 `App.tsx` 根容器的 flex 分配，不修改地图、时间轴、右侧详情的职责。

### 6. 补充统一样式，解决“无重叠、无错乱”

- 文件：`src/index.css`
- 做什么：
  - 为新的品牌文案状态、展览侧栏返回区、地图说明区补充样式。
  - 删除或替换依赖旧 breadcrumb 顶条的间距假设。
- 为什么：
  - 本次问题本质是层级冲突，不只是改文字。
- 怎么做：
  - 为展览侧栏新增独立类名，避免继续复用顶部导航视觉。
  - 为地图说明区新增更轻的视觉层级，减少其“第二导航条”观感。
  - 调整展览主内容顶部间距，填补 breadcrumb 移除后的留白。

## Implementation Order

1. 改造 `SiteTopNav.tsx`，支持按 `variant` 切换品牌标题与副标题。
2. 在 `Layout.tsx` 中移除顶部 breadcrumb 方案，建立“返回上一级”推导逻辑。
3. 重做展览桌面侧栏与移动端目录头部，让其承接层级返回。
4. 改造 `Header.tsx`，让地图页只保留一套顶部导航，模块头变为说明区。
5. 如需要，微调 `src/modules/map/App.tsx` 的高度分配。
6. 在 `src/index.css` 中补齐新版展览侧栏、地图说明区、品牌变体的样式。
7. 最后回归检查首页、展览、地图的文案、跳转、层级和移动端行为。
