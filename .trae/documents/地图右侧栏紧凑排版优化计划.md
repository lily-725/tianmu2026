# 地图右侧栏紧凑排版优化计划

## Summary

本次优化仅针对地图页右侧默认侧栏中的三个区域：

- `历史地图`
- `口述回忆`
- `时光长河`

目标是在**不改变现有设计语言**的前提下，压缩排版密度，让右侧栏在桌面端与移动端都更紧凑、更易浏览。优化重点是间距、留白、卡片内边距与段落节奏，不改配色、字体体系、组件层级和交互模式。

## Current State Analysis

当前实现位于 [SidebarDefault.tsx](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/components/SidebarDefault.tsx)。

- 右侧栏整体容器使用 `p-10`，内容区使用 `space-y-8`，整体留白偏大。
- `历史地图` 与 `口述回忆` 标题下间距为 `mb-6`，`时光长河` 为 `mb-8`，区块节奏不统一。
- `历史地图` 横向图库使用 `gap-4` 与 `pb-4`，分页点区域还有 `mt-2`，使图片区块垂直占用较高。
- `口述回忆` 卡片使用 `p-6`，头部 `gap-5`，播放器区 `mt-6 gap-4`，内部空间较松。
- `时光长河` 段落容器使用 `space-y-3`，段距已不算夸张，但在整体过宽边距下仍显松散。
- 地图页右栏容器宽度定义在 [App.tsx](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/App.tsx)，当前为 `w-[450px]`。本次不调整侧栏总宽度，以避免设计感知变化。
- 移动端在 [index.css](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/index.css) 中已有 `.p-10, .p-12` 的压缩覆盖，以及图库宽度覆盖；此次需要确保桌面端收紧后，移动端仍保持协调，不产生新的拥挤感。

## Proposed Changes

### 1. 收紧右侧栏整体骨架间距

修改文件：

- [SidebarDefault.tsx](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/components/SidebarDefault.tsx)

具体调整：

- 将顶层容器的 `p-10` 下调为更紧凑的统一内边距，例如 `p-8`。
- 将内容区的 `space-y-8` 下调为更紧凑的区块间距，例如 `space-y-6`。

原因：

- 当前视觉“松”的核心不是单一区块，而是整个侧栏骨架过于疏朗。
- 优先压缩统一骨架，能在不破坏设计的前提下整体提效。

### 2. 统一三个区块标题的上下节奏

修改文件：

- [SidebarDefault.tsx](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/components/SidebarDefault.tsx)

具体调整：

- 统一三个区块标题下边距，收敛到同一档位，例如从 `mb-6 / mb-8` 统一为 `mb-4` 或 `mb-5`。
- 保留标题字号、字距、色彩、左侧竖条与 `gap-3` 不变。

原因：

- 用户明确要求“不改变设计”，因此标题视觉样式不动，只压缩其占位。
- 统一节奏能减少段落跳变，使侧栏更整洁。

### 3. 压缩“历史地图”区块的图片与分页留白

修改文件：

- [SidebarDefault.tsx](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/components/SidebarDefault.tsx)

具体调整：

- 将横向图库容器的 `gap-4` 调低一档，例如 `gap-3`。
- 将图库底部 `pb-4` 调低，例如 `pb-2` 或 `pb-3`。
- 将分页点区域的 `mt-2` 适度减小，例如 `mt-1.5` 或 `mt-1`。
- 不修改图片宽高比 `aspect-[16/10]`、卡片阴影、边框、hover 缩放与横向滚动机制。

原因：

- “历史地图”是右栏最高的内容块之一，轻度压缩其底部与内部留白，收益最大。
- 保留图片区视觉体量和交互，不改变原有设计印象。

### 4. 压缩“口述回忆”卡片的内部排版

修改文件：

- [SidebarDefault.tsx](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/components/SidebarDefault.tsx)

具体调整：

- 将卡片内边距从 `p-6` 下调，例如 `p-5`。
- 将头部图标与文字区的 `gap-5` 下调，例如 `gap-4`。
- 将播放器区顶部间距 `mt-6` 下调，例如 `mt-4` 或 `mt-5`。
- 将播放器按钮与波形区的 `gap-4` 下调，例如 `gap-3`。
- 保持麦克风图标、播放按钮尺寸、波形布局、边框与 hover 行为不变，除非微调后出现视觉失衡。

原因：

- 该区块内部空隙较多，是桌面端“松”的第二大来源。
- 在不压缩交互控件可用性的前提下，可明显节省纵向空间。

### 5. 微调“时光长河”段落节奏，但不改变阅读气质

修改文件：

- [SidebarDefault.tsx](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/components/SidebarDefault.tsx)

具体调整：

- 视实际效果决定是否将 `space-y-3` 保持不变，或轻微下调到 `space-y-2.5` / `space-y-2`。
- 保持正文 `text-[16px]`、`leading-[1.8]` 与 `indent-[2em]` 不变，优先保留当前阅读质感。

原因：

- 用户此前已强调首行缩进与段间距要求，这一区块应以“微调”为主，不做激进压缩。
- 核心压缩应更多落在骨架与前两个模块，而非正文可读性。

### 6. 同步检查移动端适配，不新增设计偏差

修改文件：

- [index.css](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/index.css)
- 如有必要，少量补充 [SidebarDefault.tsx](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/components/SidebarDefault.tsx) 的类名

具体调整：

- 检查现有移动端规则 `.p-10, .p-12 { padding: 1.25rem !important; }` 是否仍与桌面端新间距匹配。
- 若桌面端类名从 `p-10` 改为 `p-8`，则补齐对应移动端覆盖，避免移动端失去紧缩效果。
- 保持 `aside.w-[450px]` 的移动端全宽规则与图库 `w-[85%] -> 92%` 的覆盖逻辑不变，除非新间距导致明显不协调。

原因：

- 用户已明确要求同步覆盖移动端。
- 当前移动端样式依赖具体类名选择器，桌面端类名一旦调整，必须同步更新覆盖规则。

## Assumptions & Decisions

- 本次范围仅包含地图页默认右侧栏，不包含选中点位后的详情侧栏 [FeatureDetail.tsx](file:///Users/liuyi/Desktop/地方史网站整合版/src/modules/map/components/FeatureDetail.tsx)。
- 不修改数据结构，不触碰 `historicalImages`、`oralHistory`、`evolutionNotes` 的数据拼装逻辑。
- 不改变右侧栏总宽度 `w-[450px]`，避免被感知为布局重设计。
- 不变更字体、字号体系、颜色、边框风格、阴影、图片比例、播放交互与动画逻辑。
- 优化以“减法”为主：优先减少边距和留白，而不是增加新组件或新视觉元素。

## Verification Steps

1. 运行类型或构建校验，优先执行项目现有 `build` 流程，确认修改未引入编译错误。
2. 在桌面端检查地图右侧默认栏：
   - `历史地图`、`口述回忆`、`时光长河` 三个区块之间明显更紧凑。
   - 标题视觉样式未变化，仅占位缩小。
   - 图片、播放按钮、波形与正文可读性不受影响。
3. 在移动端检查：
   - 侧栏仍为全宽堆叠。
   - 内边距与图片区布局没有因类名变更而失效。
   - 文本与播放器未出现拥挤、换行异常或点击区域过小的问题。
4. 手动切换多个时期，确认不同数据量下：
   - 有多张历史地图时分页点与图片区间距正常。
   - 有口述回忆时卡片内部布局稳定。
   - `时光长河` 多段文本的段落节奏保持自然。
